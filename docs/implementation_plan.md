# WMS 화면 구조 및 계층 개편 계획 (Restructuring)

본 문서는 서비스의 확장성과 가독성을 높이기 위해 레이아웃 뼈대(Container)와 실제 컨텐츠(Main)를 논리적으로 분리하고 명칭을 정립하는 단계별 계획입니다.

## 1. 개요
기존의 `Main.tsx`가 담당하던 **레이아웃 조립 역할**을 `Container.tsx`로 분리하고, 실제 사용자가 보는 **메인 대시보드 내용**을 `Main.tsx`로 명명하여 구조적 모호함을 제거합니다.

## 2. 작업 단계

### 단계 1: 뼈대 화면 (`Container.tsx`) 구축
- **위치**: `src/pages/Container.tsx` (특정 서비스 폴더가 아닌 pages 최상위로 이동)
- **역할**: `Header`, `Sidebar`, `MainLayout`을 조립하여 전체적인 서비스 틀을 제공합니다.
- **변경 사항**: 기존 `src/pages/Main/Main.tsx` 파일을 이 위치로 이동 및 이름을 변경합니다.

### 단계 2: 메인 컨텐츠 (`Main.tsx`) 통합 및 명명
- **위치**: `src/pages/Main/Main.tsx`
- **역할**: 공지사항 현황과 대시보드 그래프가 결합된 통합 메인 화면을 담당합니다.
- **변경 사항**: 기존 `src/pages/Home/cj_wms_home_0010.tsx` 데이터를 이 파일로 이관하고, 불필요해진 `0015` 파일은 삭제합니다.

### 단계 3: 연결 및 라우팅 업데이트
- `App.tsx` 또는 엔트리 파일에서 `Main` 페이지 호출 경로를 새롭게 정의된 `Container.tsx`로 업데이트합니다.
- 로고 클릭 시 및 초기 진입 시 `activeSideMenu` 상태값을 기본값(`""`)으로 설정하여 통합 메인 컨텐츠가 나오도록 로직을 일원화합니다.

## 3. 상세 구조 설계

### 컨텐츠 계층 (Content Hierarchy)
- **Container (뼈대)**
  - Sidebar (네비게이션)
  - Header (글로벌 액션)
  - Content Area (가변 영역)
    - **Main (통합 대시보드 + 공지사항)**
    - 기타 업무 페이지 (입고, 출고 등)

## 4. 추가 작업: 최근 트랜잭션 영역 가변 높이 (기존 작업 유지)
- **내용**: `.tx-list` 영역에 `max-height: 479px`를 적용하여 5건 기준의 가변/고정 높이 로직을 유지합니다.
